# 作业 04 · 十五五规划热词分析

> 题目：编写程序，统计十五五发展规划报告热词频率。

对《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》全文做中文分词与词频统计：按一级标题切成 15 个部分，去停用词后排出总榜与名词榜，再用每千词频次画分部分热力图。

语料规模：114 段、18,240 汉字、15 个部分、61 条；分词后 7,331 个词、2,159 个不重复词。总榜第一是「发展」173 次，且在全部 15 个部分出现。

## 运行

```bash
python demo.py corpus          # 语料规模
python demo.py table --start 1 --end 10
python demo.py table --start 11 --end 20
python demo.py nouns           # 名词榜 TOP12
python demo.py sections        # 每个部分的门面词
python demo.py render          # 柱状图、词云、热力图
python demo.py all

python -m pytest -q            # 32 条用例
```

重新抓取语料（需联网）：

```bash
python tools/fetch_text.py
```

## 说明

- 语料是《建议》（2025-10-28 发布，约 2 万字），**不是** 2026 年发布的《纲要》；结论只适用于《建议》全文。
- 中国政府网原文页面对 `requests` 返回反爬空壳（body 仅 62 字、无 `<p>`），因此正文取自维基文库的 MediaWiki API，并在 `fetch_text.py` 里剔除导航与版权模板。
- 截图 01~09 全部来自本机真实运行；控制台截图使用新宋体 12×24，pytest 截图为 `python -m pytest` 的真实窗口。
