# 作业 03 · 蒙特卡罗手搓图形

> 题目：蒙特卡罗方法手搓图形。

不描边、不调用绘图图元：在一个矩形框里均匀撒随机点，落在图形内部的点留下来，几万个点自己堆出轮廓；命中率乘矩形面积，顺手把图形面积也估出来。

四个图形：圆（π）、心形（隐函数）、五角星、科赫雪花（多边形）。每个图形撒 20 万点，相对误差都在 1% 以内。

## 运行

```bash
python demo.py metrics    # 面积表 + π 收敛表
python demo.py render     # 点画、四图对比、收敛曲线
python demo.py all

python -m pytest -q       # 24 条用例
```
