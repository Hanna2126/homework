Python 课程作业合集。每份作业一个目录，包含源码、pytest 用例、真实运行截图和一篇博客。

## 目录约定

- 每份作业一个 `NN-题目` 目录，编号按提交顺序递增；
- `src/` 放实现，`tests/` 放 pytest 用例，`截图/` 放本机真实运行截图，`blog/` 放博客与配图；
- 博客里的图片统一放 `blog/images/`，方便整段复制到其他平台；
- 每份作业目录下都有独立的 `README.md`，写清题目、运行方式和输出规格。

## 环境

- Windows 11
- Python 3.13.18
- pytest 9.2.0
