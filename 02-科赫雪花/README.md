# 作业 02 · 科赫雪花

> 题目：绘制科赫雪花，根据阶数生成（0~4 阶）。

用复数做纯几何的递归：每条线段换成 4 条、长度变为原来 1/3，三条边拼成闭合雪花；0~4 阶共 768 条线段、769 个顶点，周长按 `(4/3)^n` 发散，面积收敛到初始三角形的 `8/5`。

## 运行

```bash
python demo.py metrics    # 0~4 阶的线段数、周长、面积
python demo.py render     # 生成 6 张 PNG 到 截图/
python demo.py all        # 两者都跑

python src/draw_turtle.py 4   # 教材式 turtle 画法（需要可用的 tkinter）
python -m pytest -q           # 30 条用例
```

## 输出规格

| n | 每边线段 | 总线段 | 周长 | 面积 | 面积/初始 |
| --- | --- | --- | --- | --- | --- |
| 0 | 1 | 3 | 3.0000 | 0.43301 | 1.000 |
| 1 | 4 | 12 | 4.0000 | 0.57735 | 1.333 |
| 2 | 16 | 48 | 5.3333 | 0.64150 | 1.481 |
| 3 | 64 | 192 | 7.1111 | 0.67001 | 1.547 |
| 4 | 256 | 768 | 9.4815 | 0.68268 | 1.577 |

初始边长 1；面积极限 `2√3/5 ≈ 0.69282`。
